# MercadoLibre Scraper

Este proyecto automatiza la búsqueda de "playstation 5" en MercadoLibre México, aplicando filtros específicos y extrayendo información de los primeros 5 productos.

## Requisitos

- Python 3.7 o superior
- Google Chrome
- ChromeDriver compatible con tu versión de Chrome
- Selenium

## Instalación



1. Navega al directorio del proyecto:
   cd mercadolibre_scraper

2. Instala las dependencias:
   pip install -r requisitos_previos.txt

## Uso

Ejecuta el script con:
   python main.py
